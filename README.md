# Coding Test Study

Java 코딩테스트 학습 및 문제 풀이 기록

## Commit Convention

| Type | 설명 |
|------|------|
| `solve` | 새로운 문제 풀이 추가 |
| `docs` | README 및 학습 내용 수정 |
| `refactor` | 기존 풀이 개선 |
| `fix` | 잘못된 코드 수정 |

### Example

```bash
git commit -m "solve: 18-두 개의 수로 특정값 만들기"
```

## 기본 규칙

새로운 문제의 `Solution.java`와 `README.md`를 함께 추가할 때:

```text
solve: 문제명
```
